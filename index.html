常见问题

广告位怎么投放？

打开发布页填写广告标题、描述和落地页链接，复制生成的卡片代码，粘贴到首页广告墙对应位置提交即可上线。投放详情可以看投放指南。

支持跳转到哪些链接？

支持 http 和 https 协议的网址，点击后经中转页跳转到广告主指定的落地页，其他协议会被拦截。

站点是静态的吗？需要服务器吗？

站点为纯静态页面，托管在 GitHub Pages，没有数据库和后端依赖，提交代码后自动构建发布。

关于本站

本站是一个轻量广告投放展示页：广告位以卡片形式集中呈现，访客点击后经中转页跳转到广告主指定的落地页。站点为纯静态页面，托管在 GitHub Pages，无数据库、无后端依赖。

投放方式：打开发布页生成卡片代码，粘贴进 index.html 的广告墙区域，提交即生效。
