FAQ

常见问题

投放广告需要什么？

需要一个投放密钥。在投放页点“输入密钥”，验证通过后就能生成广告卡片。有效期分 7 天、1 个月、3 个月、6 个月、1 年和长期。

密钥怎么买？

联系 Telegram @tg7879，说明要哪种有效期，拿到密钥后到投放页输入即可。到期后自动失效，续期也是同一个渠道。

密钥能重复用吗？

一个密钥对应一次授权，有效期从签发日算起。站点只存密钥的哈希，后台看不到明文，弄丢了只能重新签发。

广告链接有要求吗？

只放行 http 和 https。其他协议会被跳转页拦下，防止 javascript: 这类链接。

站点需要服务器吗？

不用。整站是静态 HTML，放在 GitHub Pages 上，推代码自动构建，没有数据库。点击数只记在访问者浏览器本地。
