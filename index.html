常见问题

怎么把广告放上去？

打开发布页，填标题、描述和落地页链接，点生成代码，把那段 HTML 复制到 index.html 的广告墙里，提交后就上线。改一个字也是同样的流程，没有后台要登录。具体步骤写在投放指南里。

链接有要求吗？

只认 http 和 https。其他协议一律挡在跳转页外面，防止有人拿 javascript: 之类的东西做手脚。

站点要服务器吗？

不用。整站是静态 HTML，放在 GitHub Pages 上，推代码自动构建。没有数据库，点击次数只记在浏览器本地，用来自己看效果，不上报。

关于本站

这站只干一件事：把几条广告位摆出来，点一下把人送到广告主给的页面。全部是静态页面，托管在 GitHub Pages，没有后端，也没有数据库。

加广告的流程就三步：发布页生成卡片、粘进 index.html 的广告墙、push。想改样子就改 assets/style.css。
