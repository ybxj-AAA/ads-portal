常见问题

与投放直接相关的几条，其余的写在投放指南里。

怎么把广告挂上去？
点页面上的「我要投放」，输入密钥，填标题、描述和落地页链接，生成一段卡片代码，贴到本页广告墙提交就行。
密钥有几种？
7 天、1 个月、3 个月、6 个月、1 年和长期，从签发日算起。到期后投放页会重新锁上，续期换新密钥。
链接有什么限制？
只放行 http 和 https。别的协议会被跳转页拦下来，避免 javascript: 这类东西。
站点要服务器吗？
不用。整站是静态文件，放在 GitHub Pages 上，提交后自动构建，没有数据库。
